# AiSD

Algorithms and data structures in Python: a linked list, a queue, a stack, a tree and a binary search tree, with tests. 49 commits.

University coursework from my Computer Science studies at UWM (2020–2024). I wrote the code by hand; the commit history is unchanged. This README was added in November 2026.

Years of work: 2021–2022 (first commit on 8 October 2021, last commit on 16 January 2022).

## Contents

- `lab01/`: 10 short functions, for example initials from a name and a palindrome check.
- `lab02/`: `LinkedList`, `Queue` and `Stack` classes.
- `lab03/`: recursion tasks, for example numbers from n down to 0 and n-digit numbers with equal sums of digits at even and odd positions.
- `lab04/`: a general tree (`Tree`, `TreeNode`).
- `lab05/`: a binary tree (`BinaryTree`, `BinaryNode`), tests in `tests.py` and a homework.
- `lab06/`: a binary search tree; `BinarySearchTree.py` has a syntax error at line 14.
- `lab07/`: a graph (`Vertex`, `Edge`, `EdgeType`, `Graph`).

## Running

```
cd lab05 && python3 tests.py
```

Result on 26 November 2026 (Python 3.14): the assertions pass and the script prints the binary tree.
